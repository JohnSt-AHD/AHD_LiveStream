Competitive comparison — 270 devices · 4-month season · ops / tracking + virtual livestream

Altitude HD · 22 June 2026

Scope: 270-device fleet · 4-month season · 8 regattas · 32 tracking days. Two tiers: ops / tracking only (fleet + platform + data) vs + virtual livestream (2D race viewer / on-air graphics — no on-site cameras). CrewSight season quote is ops / tracking at $51,900 — vMix / AHD overlay feeds supported, regatta production not included. Optional CrewSight virtual livestream add-on: $750/regatta day × 32 days = $24,000. GeoRacing per Trimaran preliminary budget: tracker purchase €140/unit; Safety €150/day · Fan Experience €300/day + API €200/day for public/broadcast. SIMs not included in GeoRacing hardware quote — comparison adds $10/SIM/mo for parity. EUR → NZD @ 1.82.

IoT data rate for this variant: $10/SIM/month (previous baseline $5/SIM/month).

M26 field validation (14 Jun 2026)

Field test 14 Jun 2026: 11:30–11:45 NZST drive (~10 km) at ~1 Hz. M26 median GPS accuracy 3.3 m (p90 5.2 m) vs S21 reference 5.2 m; fix continuity 1 s max gap on M26. Track agreement median 4.2 m.

Battery 14 Jun 2026: 96% @ 06:45 NZ → 64% after 10.3 h (~3.1 %/h at 1 Hz GPS + background recording; ~32 h from full charge; app data 36 MB). An 8-hour active day at 1 Hz uses ~25% — no mid-day charge required.

Ops / tracking (CrewSight $51,900): GPS fleet, platform, and data — vMix / AHD overlay feeds supported for livestream (regatta production quoted separately). Virtual livestream optional — CrewSight at $750/regatta day (32 days = $24,000); GeoRacing Fan Experience + API (€300 + €200/day). 2D race viewer / broadcast API; no on-site cameras.

CrewSight strengths

  • Capsize alert · Custom rowing dashboard · Designed for NZ regatta programme
  • Livestream supported — vMix / AHD overlay feeds in ops tier · optional virtual livestream at $750/regatta day
  • Rowing boat mounting optional; competitors do not supply shell mounting

Summary

Ops / tracking: CrewSight $51,900 vs LoRa $67,000 vs GeoRacing $89,788 (€43,400 + modelled SIM). + Virtual livestream: CrewSight $75,900 (+$24,000 at $750/day) vs GeoRacing $110,172 (€54,600 + SIM). Neither vendor includes on-site cameras. Both CrewSight and GeoRacing are purchase-based CAPEX; GeoRacing adds per-event licensing.

Optional CrewSight mounting (270 boats): +$13,500 ex GST. LoRa gateway WAN backhaul not itemised. GeoRacing pricing from Trimaran preliminary budget email; tax/shipping/SIM configuration extra.
