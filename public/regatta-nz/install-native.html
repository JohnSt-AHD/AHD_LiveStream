Install Regatta NZ

Android APK for the spectator app — schedule, follow clubs, and live course (same web app as the browser).

Download

Download Regatta-NZ.apk

Or open GitHub Releases if the direct link 404s (re-run Actions → Regatta NZ APK).

Install on phone

  1. Open the downloaded APK (Chrome / Files).
  2. Allow Install unknown apps for that app if prompted.
  3. Tap Install → Open. The app loads the live site at ahd-livestream.vercel.app.

Web (no install)

Open Regatta NZ in the browser · Hub Setup configures regatta code and livestream.
